# Go Base Toolkit

Компактный набор утилит на Go для работы со слайсами, map и строками, собранный в один проект.
Пакеты связаны demo-сценариями: числа → collections, текст → string + map, отчёт → report + string.

## Что это

Цельный toolkit, демонстрирующий базовые темы Go:

- слайсы и их преобразования (filter, square, dedup, clone, chunk);
- map и агрегация (частота, группировка, top-N);
- строки и руны (регистр, разбиение, очистка, юникод);
- построение текстового отчёта с нормализацией ключей.

Все функции покрыты тестами, включая edge cases: пустой и `nil` вход, невалидный UTF-8, дубликаты, сортировка, tie-break.
